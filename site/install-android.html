📱 Nœud B · worker QUIC · campagne CH3/S4

Installer le worker de mesure
sur ton téléphone Android

Le PC (nœud A) prépare tout : installe d'abord le kit depuis la page Windows — son étape « préparer le téléphone » pousse le binaire et les scripts vers Termux. Cette page démarre le worker et vérifie l'installation.

1

Installer Termux (F-Droid)

prepare-device.sh (côté PC) installe Termux automatiquement s'il est absent. Pour l'installer toi-même, prends l'APK F-Droid (la version Play Store n'est pas compatible) :

# Sur le téléphone : télécharger puis installer l'APK F-Droid https://f-droid.org/fr/packages/com.termux/

Une fois installé : ouvre Termux une fois (crée son espace de données), puis exécute dedans :

termux-setup-storage
Autorise l'accès stockage : c'est le canal par lequel le binaire, la clé publique du PC et l'offre de session transitent.
2

Récupérer le kit dans Termux

Si prepare-device.sh a été lancé côté PC, tout est déjà sur /sdcard. Dans Termux :

# crée ~/campaign et copie le kit depuis /sdcard/Download mkdir -p ~/campaign && cd ~/campaign cp /sdcard/Download/quic-spike ./quic-spike cp /sdcard/Download/quic-spike.SHA256SUMS ./quic-spike.SHA256SUMS 2>/dev/null # les scripts du worker (poussés par prepare-device.sh) : cp /sdcard/Download/campaign/worker-start.sh ./worker-start.sh cp /sdcard/Download/campaign/check-termux.sh ./check-termux.sh chmod 700 ./quic-spike
Binaire introuvable sur /sdcard ? Lance bash scripts/campaign/android/prepare-device.sh sur le PC, puis reviens.
3

Vérifier l'installation

Lance le vérificateur dans Termux, copie sa sortie (appui long → Copier), et colle-la ci-dessous :

bash check-termux.sh
4

Démarrer le worker

Choisis la liaison : Wi-Fi (PC et téléphone sur le même réseau) ou USB (redirection adb, aucun réglage pare-feu) :

# Wi-Fi — le script détecte et annonce l'IP du téléphone : bash worker-start.sh # USB — via la redirection adb tcp:7700 établie par le PC : ADVERTISE=127.0.0.1:7700 bash worker-start.sh

Le worker affiche sa clé publique et attend les connexions du PC. L'offre de session est publiée automatiquement vers /sdcard/Download/campaign/offer.json toutes les 3 s (jeton TTL 30 s).

5

Revenir au PC pour la campagne

Le worker tourne ? Retourne à la page Windows, dernière étape — le PC orchestre les mesures.

📱 Node B · QUIC worker · CH3/S4 campaign

Set up the measurement worker
on your Android phone

The PC (node A) prepares everything: first install the kit from the Windows page — its "prepare the phone" step pushes the binary and scripts to Termux. This page starts the worker and verifies the installation.

1

Install Termux (F-Droid)

prepare-device.sh (on the PC) installs Termux automatically if missing. To install it yourself, use the F-Droid APK (the Play Store build is not compatible):

# On the phone: download then install the F-Droid APK https://f-droid.org/fr/packages/com.termux/

Once installed: open Termux once (this creates its data space), then run inside:

termux-setup-storage
Grant the storage permission: it is the channel through which the binary, the PC's public key and the session offer travel.
2

Retrieve the kit in Termux

If prepare-device.sh was run on the PC, everything is already on /sdcard. In Termux:

# create ~/campaign and copy the kit from /sdcard/Download mkdir -p ~/campaign && cd ~/campaign cp /sdcard/Download/quic-spike ./quic-spike cp /sdcard/Download/quic-spike.SHA256SUMS ./quic-spike.SHA256SUMS 2>/dev/null # the worker scripts (pushed by prepare-device.sh): cp /sdcard/Download/campaign/worker-start.sh ./worker-start.sh cp /sdcard/Download/campaign/check-termux.sh ./check-termux.sh chmod 700 ./quic-spike
Binary missing from /sdcard? Run bash scripts/campaign/android/prepare-device.sh on the PC, then come back.
3

Verify the installation

Run the checker in Termux, copy its output (long-press → Copy), and paste it below:

bash check-termux.sh
4

Start the worker

Choose the link: Wi-Fi (PC and phone on the same network) or USB (adb forwarding, no firewall setup):

# Wi-Fi — the script detects and advertises the phone's IP: bash worker-start.sh # USB — through the adb tcp:7700 forwarding set up by the PC: ADVERTISE=127.0.0.1:7700 bash worker-start.sh

The worker prints its public key and waits for the PC's connections. The session offer is published automatically to /sdcard/Download/campaign/offer.json every 3 s (30-s one-time token).

5

Back to the PC for the campaign

Worker running? Return to the Windows page, final step — the PC orchestrates the measurements.
